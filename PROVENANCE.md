# Source provenance

The node source is the published `1.8.1-tavchain.eval1` release-source snapshot, derived from Cronos commit `616274a74d4f4747e67fad7f895c000e90a3ec6a`. Its source archive SHA-256 is `ddb806fc453f6d0dc466c37244733fea57d09ef045346750cf19d4c4a68c1a48`.

All files under `node/`, including required upstream notices and modification records, are retained byte-for-byte. See [node/TAVCHAIN-MODIFICATIONS.md](node/TAVCHAIN-MODIFICATIONS.md) and the authenticated release documents linked from the README. Dependencies retain their respective licenses; the root Apache license does not relicense those dependencies.

This public repository begins with a source snapshot. Earlier private prototype history and private acceptance infrastructure are not imported. No prior implementation is presented as independently authored Tavchain code.

The separate native full-node release includes four packaging changes, source, build instructions and notices. It is linked from the README and is not silently substituted for the validator source snapshot.
