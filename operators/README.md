# Full-node packaging
The docker directory contains the unchanged packaging source from the authenticated Tavchain Docker release. The large bin/tavchaind executable is deliberately not stored in Git.
For the complete runnable package, use the docker-771002-1 release archive, including its executable and original internal checksums. Do not run the incomplete source directory as if it were the complete archive.
Existing guide: https://docs.tavchain.safeney.com/tavchain/operate/node-docker
A prebuilt public-registry image remains a separate pending distribution improvement. No image name or digest is promised here.
The original package README and notices are retained. Existing Apache 2.0 packaging permission and dependency terms apply.
