# Contributing

Tavchain is derived from Cronos. Preserve upstream attribution and applicable licenses.

For setup and network instructions, start with [README.md](README.md). The source root is `node/`. The native packaging changes are distributed separately with the authenticated native release; see the README downloads section.

Open an issue describing the problem before proposing a substantial protocol or dependency change. For a pull request, describe the resulting behavior, relevant upstream references and the checks performed. Keep changes focused, include regression coverage where appropriate, and disclose any checks you could not run. Never submit operational keys, credentials, databases or personal information.

Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).
